# AI 可编辑幻灯制作工作流

一个面向 Codex 的幻灯制作技能：用 AI 探索页面视觉，再把文字、数据和基础图形重建为 PowerPoint 原生对象，兼顾视觉表达与后续编辑。

## 解决什么问题

常见做法各有取舍：程序排版便于逐项修改，但页面视觉需要额外设计；整页生图视觉完整，却难以直接改字和数据。本工作流按页面内容选择制作方式：

| 页面类型 | 推荐方式 |
| --- | --- |
| 表格、列表、数据比较、可编辑图表 | 原生 PowerPoint 排版或程序生成 |
| 复杂概念、临床流程、示意插画 | AI 生成视觉参考，再按需重建为可编辑对象 |
| 同页兼有图文与数据 | 复杂插画保留为独立图片；文字、数据、简单图形用原生对象 |

## 工作流程

1. 明确听众、目的、页数、版式、输入材料和可编辑要求。
2. 建立事实底稿，记录主张、数值、单位、版本、来源和限定条件。
3. 先完成逐页大纲，明确每页标题、核心信息、证据、视觉形式和来源。
4. 按页面类型选择原生排版、生图参考或混合方式，不强迫每页都生图。
5. 设定版式、字体层级、配色和复用组件，先做样稿再批量制作。
6. 将视觉参考图与权威原文一并用于重建：文字和数据独立成框，简单图形用原生形状，复杂插画作为独立图片。
7. 核对事实、逐页检查渲染效果，并实际验证关键对象是否可编辑。
8. 交付所请求的 PPTX 和预览文件，说明可编辑范围与尚未验证项目。

## 关键原则

- 原文和经核验的来源是事实依据，生成图片只用于视觉参考。
- 不以文件扩展名推断可编辑性；必须检查 PPTX 中的对象并试改关键内容。
- 保留用户指定的页数、语言和交付边界。用户只要大纲时，不继续制作幻灯。
- 医学与科学内容需核对研究人群、治疗方案、样本量、终点、数据版本、统计量、安全性和结论限定语。
- 公开仓库不包含本地路径、账号信息、凭据或用户提供的私人源文件。本仓库未指定开源许可证。

## 安装与使用

将 `ai-editable-slide-workflow/` 放入 Codex 用户技能目录，或在支持 Codex Skills 的环境中安装该目录。新任务可显式调用：

```text
$ai-editable-slide-workflow
```

也可直接描述目标，例如：“请按可编辑幻灯工作流，根据这些材料制作 12 页 PPTX。”如果要求“先做大纲，不生成幻灯”，技能会停在大纲阶段。

## 文件结构

```text
ai-editable-slide-workflow/
├── SKILL.md
├── README.md
├── agents/
│   └── openai.yaml
└── references/
    ├── medical-evidence-check.md
    └── prompts.md
```

`references/prompts.md` 提供视觉样稿、可编辑重建和整套幻灯 QA 提示词；`references/medical-evidence-check.md` 提供医学与科学内容的事实核验清单。
